- data is carried in packets
- each packet has a header and a payload
- header contains IP addresses of the sender and reciever and metadata
- payload contains the actual data

*OSI model*

- **physical layer**: deals with the physical devices of a network
- **data-link layer**: manages access to data link layer and provides error correction and congestion control services
- **network layer**: logical addressing and routing
- **Transport layer**: end-to-end communication and flow control
- **session layer**:manages sessions b/w applications and handles synchronization, dialog control and token management
- **presentation layer**:translates data b/w application layer and the lower layers
- **application layer**:provides network services to end users
